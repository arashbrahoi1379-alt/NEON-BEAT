NEON BEAT — پروژه اندروید آزمایشی
=================================
این پروژه یک پوسته اندرویدی WebView است که نسخه HTML فعلی دمو را داخل اپ باز می‌کند.
این بازی هنوز نسخه نهایی سه‌بعدی/Native نیست و تبلیغات AdMob واقعی یا Firebase به آن متصل نشده‌اند.

ساخت APK رایگان از طریق GitHub Actions:
1) فایل ZIP را از حالت فشرده خارج کن.
2) در GitHub یک مخزن جدید بساز.
3) همه محتویات این پوشه را در مخزن آپلود کن (محتویات پوشه، نه خود پوشه).
4) از تب Actions، workflow با نام Build NEON BEAT APK را اجرا کن؛ یا یک commit بزن.
5) پس از پایان موفق، وارد اجرای workflow شو و از بخش Artifacts فایل NEON-BEAT-debug-apk را دانلود کن.
6) ZIP خروجی را در گوشی باز کن و app-debug.apk را نصب کن. ممکن است اندروید اجازه نصب از منبع ناشناس بخواهد.

نیازمندی: حساب GitHub رایگان. این پروژه خودش را به Firebase متصل نمی‌کند؛ پنل Firebase starter جداگانه است.
